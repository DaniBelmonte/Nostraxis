# Code of conduct

Nostraxis is committed to a welcoming, safe and constructive community.

## Expected behavior

- Be respectful and assume good intent.
- Give specific, actionable feedback about the work rather than the person.
- Welcome contributors with different backgrounds and levels of experience.
- Respect privacy. Never publish another person's prompts, credentials, local paths or session data.
- Accept maintainer decisions gracefully, including decisions about scope and project direction.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized attention, deliberate intimidation, doxxing and sustained disruption are not tolerated in project spaces or when representing the project.

## Enforcement

Maintainers may edit or remove contributions, comments or other participation that violates this code. Repeated or serious violations may result in a temporary or permanent ban from project spaces.

Report conduct concerns privately to the maintainer using the contact information on [DaniBelmonte's GitHub profile](https://github.com/DaniBelmonte). Reports will be handled with discretion. Do not include sensitive third-party data unless it is necessary to understand the incident.
